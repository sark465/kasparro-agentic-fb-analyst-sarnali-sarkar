# Evaluator Agent
-----------------

## 🎯 Objective
Quantitatively validate or reject each hypothesis generated by the Insight Agent, using dataset metrics and predefined thresholds from `config.yaml`.

---

## 🧩 Input
- `hypothesis`: A structured hypothesis object from the Insight Agent.
- `raw_data_summary`: Relevant subset of campaign data used to verify the hypothesis.

---

## 📤 Expected Output (JSON Schema)
```json
{
  "hypothesis_id": "string",
  "result": "supported | not_supported | inconclusive",
  "metric_checks": [
    {"metric": "string", "baseline": "float", "current": "float", "p_value": "float"}
  ],
  "confidence": "float (0-1)",
  "evidence": "string"
}
